# 遗物采集规则（更新于2026-09-10，v7）

2026-09-11 卡牌限制更新：真实历史中的任务/状态/衍生牌已开放；藏宝图、探寻、愧疚、疯狂科学的持久状态已适配。下文历史限制中的“未适配持久状态”不再包括这些字段，详见 [特殊卡牌与持久状态](card-state.md)。其余遗物及角色限制保持。

用户授权：保留遗物身份，跳过已经发生的获得效果，保留真实历史中的卡牌、升级和附魔；影响最大生命的遗物单独移除，统一70/70开战。持续战斗效果由原版执行，不能随获得效果一起删掉。

## 此次增加的支持

40种遗物加入明确允许清单，依据本地游戏0.111.0反编译核对获得逻辑：删牌、变牌、加牌、升级、附魔、金币或奖励不再执行第二次。完整ID清单及这批源局的覆盖数见 `evidence/relic-pickup-20260906/assessment.json`。

血染玫瑰保留战斗加能量，大～抱抱保留洗牌加煤灰，腰带扣保留无药水时的敏捷。异鸟宝宝与佩尔的士兵使用合法的默认外观，仍在开战时召唤宠物；皮肤字段不参与掉血模型。尘封魔典的所选卡牌标识只用于获得效果与提示，实际升级卡牌从来源历史导入，不重新抽取。

涅奥骨骰不重新发奖励。额外先古遗物必须是来源中实际获得并持有的涅奥候选，最多两个，且源历史确实选择了涅奥骨骰；不能据此加入二三层先古遗物。已有神化、压制、涅奥之怒及相关遗物继续保留。

## 欧罗巴斯之触

静默猎手在第二幕选择欧罗巴斯之触 (`TOUCH_OF_OROBAS`) 时，原版把蛇之戒 (`RING_OF_THE_SNAKE`) 原位替换为龙之戒 (`RING_OF_THE_DRAKE`)，欧罗巴斯之触自身保留。导入器核对真实选择、获得/移除记录、保存的替换标识和最终遗物顺序。第三幕继承该状态；后续变异保护龙之戒与先古遗物。

原生采集从蛇之戒开局，不单独注入龙之戒；只对欧罗巴斯之触执行一次原版获得效果，完成确定性的替换。其他遗物继续跳过获得效果，真实卡牌、升级、附魔和普通计数保持原策略。龙之戒在前三回合各额外抽两张牌，由原版执行。原生观察仍严格核对完整开战构筑；不完整或矛盾的替换历史继续拒绝。
