# 全自动爬塔目标与进度

用户目标（2026-11-01）：单人静默猎手 A10 全流程自主操作；遗物主要按即时战斗力评分并从模型输入排除不支持遗物；事件按具体事件决策；规划可见地图路线；禁止读取未来怪物、事件或奖励与 RNG；困难/Boss 高死亡风险时扩大选牌搜索；短期/长期初始权重 0.35/0.65。实现后完成 100 局真实游戏评测，据此选超参数。

用户追加规则：非艰难局面的可跳过卡牌奖励，仅当最佳选牌综合分数严格大于跳过分数 + 1 时拿牌；等于阈值也跳过。艰难局面不套用该固定门槛。阈值统一配置并纳入测试。

- conservative 种子 `ABTUNE20261101W15R0` 在第二幕获得 `SEA_GLASS` 后失败。原生 `AncientChoiceHistoryEntry.TextKey` 取标题倒数第二段，而该遗物标题包含角色段，记录为 `DEFECT`，被模型来源校验拒绝。

- 因行为适配代码变化，`reports/baseline`、`reports/conservative` 及其重试统一降为诊断；终局也不计正式 100 局。下一版在 `reports/v2/` 固定修正后的单一代码版本，沿用预先定义的参数组和种子，不用前一版中间成绩修改参数。
