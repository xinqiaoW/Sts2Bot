# 真实构筑的一代变异

正常采集的独立 runtime 共用三个队列，按领取次数分配真实 50%、本页普通变异 25%、[专项变异](targeted-mutations.md) 25%，空队列可借用。worker 数量由运行配置决定。两个变异队列 pending 各低于 600 时补充 100 个构筑，即使真实仍有任务也会生成。本页策略为 `configs/mutations-8s.json`；活动库 `data/collection-mutations-v2.sqlite`；备份位置与周期见[持续采集](continuous-collection.md)。

## 抽样与变化

| 维度 | 规则 |
| --- | --- |
| 地图 | 荣耀 60%，巢穴 40% |
| 大小 | 小变异 60%，大变异 40% |
| 变化对象 | 只改牌、只改遗物、同时改牌和遗物，三者等概率 |
| 小变异 | 1–2 张牌和/或 1–2 件普通遗物 |
| 大变异 | 3–6 张牌和/或 1–4 件普通遗物 |
| 父代 | 已有有效结果的真实来源构筑，按卡牌组成分组后抽样，只变异一代 |

比例是概率，不是每批精确配额。净多重集差异核验实际修改数；抵消改动的候选重新生成，保持已选地图、大小和变化对象，避免拒绝率改变抽样比例。策略变更保存在 `collection_settings.mutation_policy_history`，按生成序号核验，不回写旧构筑。

卡牌通过添加、删除、替换或升级变化。新增牌来自合法普通静默/无色牌池；未改牌保留升级、附魔与持久状态，新增牌不随机附魔。牌组上限 45，无色牌最多 5。任务/事件/状态/衍生牌可随真实父代继承，不因此进入新增普通牌池。

普通遗物范围为 Common/Uncommon/Rare/Shop。初始、先古和其他特殊遗物保持身份、顺序及计数；龙之戒等替换后的初始遗物同样保护。未删遗物顺序不变，新遗物追加末尾并采样合法计数；已发生的获得效果不重复执行。

## 目标、标签与身份

保留父代的幕、地图与真实先古来源，仅继承其已核实的同幕 f−2 到 f+2 目标并集，不扩展全幕。使用 `configs/real-runs-8s.json` 时，`mutations-targeted-8s.json` 名单中的目标安排 24 个种子，其他目标仍为 4 个；前 4 个种子保持原值，遗物计数保持一致。继续使用 8 秒 Medium/short_only、DOP 1、120 秒整场期限、A10、70/70、无药水和有效终局验收。

不按掉血挑强父代，也不剪掉弱构筑结果。`mutation_lineage` 保存父子关系和变化，`mutation_target_origins` 保存目标继承链。变异输入不是新的真实 `.run`；结果、失败、隔离分别写入变异库，训练划分保留血缘连通组。

页面独立展示变异批次、父构筑编号与变更清单；真实及历史批次保留，见[查看数据](data-viewer.md)。旧变异 v1 已封存，不继续写入或重标协议。
