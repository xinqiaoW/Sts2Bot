# 抽象拟合模拟器 v0（已退役，2026-09-15）

`feat/rl-combat-env` 分支第一步做的纯 Python 全局模拟器。它不启动游戏：地图、遭遇池、奖励、商店、篝火、事件、上古的规则全部从公开 `.run` 历史里**拟合**出来（`sim/tables.py`），战斗结果由训练好的期望掉血模型 F 给出（`sim/oracle.py`）。`sim/calibrate.py` 把它和留出的真人局逐层对比，偏差报告在 `reports/20260914-215935/deviation.md`。

## 为什么退役

用户在审阅后指出：想要的是"便宜、但和游戏没有任何差别的环境"，而 v0 连游戏规则都是拟合的（地图行类型权重、未知房间分布、事件结果分布、商店库存等）。拟合规则有两个无法用校准报告消除的问题：

- 策略会学到拟合分布的缝隙（Goodhart），而真实游戏里这些缝隙不存在；
- 局面越偏离真人数据（RL 恰恰会往那里走），拟合表越没有支撑。

因此改走**路 B**：用真实游戏作为环境，通过 `RunController` mod 让 Python 接管局外决策；战斗可按需用 F 跳过以提速。设计见 `docs/run-controller.md`。

## 可回收的部分

- `sim/history.py`：把 `.run` 展平成逐层记录（房间类型、遭遇、HP/金币前后、奖励、事件选项），路 B 的行为克隆数据和"真人 vs 机器人"对比仍需要同样的展平逻辑。
- `sim/oracle.py`：F 作为战斗预言机的封装（含 stateful 卡剥离和集成推理），路 B 的"跳过战斗"直接复用。
- `sim/calibrate.py` 中的逐层统计和报告排版可以改成对比"真实游戏 + 机器人策略"与真人局。
- 校准报告中已经验证的一个结论仍然成立：F 在真人卡组上的偏差约 +0.46 HP（不含药水），可作为跳过战斗时的置信参考。
