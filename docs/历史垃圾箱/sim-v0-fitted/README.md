# 抽象拟合模拟器 v0（已退役）

此目录保留纯 Python 整局模拟器及固定校准报告。它不启动游戏，地图、遭遇、奖励、商店、篝火、事件和先古规则来自公开 `.run` 的经验拟合，战斗由预期掉血模型 F 估计。拟合分布不能保证与原版规则等价，偏离真人数据的策略也可能超出拟合覆盖，因此不作为现行强化学习环境。

现行整局环境使用真实游戏与 [RunController](../../run-controller.md)。通过 F 跳过战斗仍属于待验证方案，尚未接入该环境。

| 路径 | 归档内容 |
| --- | --- |
| `sim/` | 原 `sim` 包及其设计说明 |
| `test_sim.py` | 原模拟器测试 |
| `reports/20260914-215935/` | 固定校准报告与汇总 |

归档代码没有调整 import，不能直接按原仓库根目录命令运行。`sim/history.py` 的历史展开和 `sim/calibrate.py` 的统计方法可作为参考；`sim/oracle.py` 的状态简化及 F 结算不能未经验证直接复用于原生整局环境。报告中的偏差只描述该固定数据与假设，不是跳过战斗的可靠性保证。
