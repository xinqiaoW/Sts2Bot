# 自动爬塔早期版本演进归档（2026-11-01）

- **全流程局外接管（0.30.1–0.30.3）**：`RunControlSession` 从仅导出地图扩展为导出地图、先古/普通事件、战后奖励、卡牌选择、商店、篝火、宝箱及嵌套子界面；通过 `RunControlUnlockScope` 在独立对局创建期间启用完整内容解锁与发现；接入实机遗物累计计数规范化（`normalize_relic`）与按有效战斗次数归一化的短期评分。
- **三组参数 60 局对比（`cb5c702`，0.30.3）**：在 20 个配对种子上完成 `baseline`、`conservative`、`growth` 三组共 60 局自然终局（8,099 次决策通过审计），三组均为 0/20 胜，平均终局楼层分别为 34.70、34.45、33.15（Wilson 95% 区间 0–16.11%）。
- **商店、搜索设置与通信修复（0.30.4–0.30.6）**：调整商店删牌/药水/金币估值与危机购买优先级；修复商店同名牌实例定位；新增 `combat_search_mode="settings"` 支持读取独立存档内 CombatSolver 搜索设置；修复 Windows 下 `decision.json` 原子替换与读取共享锁冲突；战后奖励改为固定 rollout 深度（默认 3，危机加深）。
