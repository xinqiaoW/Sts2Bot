# RunController M1 原生协议验收归档

本页归档 `RealRunEnv` 最初 M1（`decision_mode="map"` 地图控制阶段）在独立 Wine 环境下的协议与控制链验收记录。全流程局外决策（`decision_mode="all"`）的后续进展见 [自动爬塔进度](autobot-progress.md)，当前协议说明见 [RunController](run-controller.md)。

## 构建与协议检查

- .NET 9 Release 构建及架构门禁通过；Python 客户端单元测试覆盖连续 `reset/step`、ID/序号隔离、非法动作、独占目录、失败结果、退出与超时锁保留。
- 原生协议检查 7/7 通过：错误 run ID、过期序号、越界、缺少 `choice` 和等待动作超时均明确报错；单场 `SMOKE-001` 在同一原生进程内两次 Passed。
