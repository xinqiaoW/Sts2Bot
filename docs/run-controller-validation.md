## 覆盖边界

目前证据证明了原生整局控制链可运行，不证明基线策略强度或所有内容均已验收。第三幕、胜利终局、所有特殊事件及事件内战斗组合，仍需按实际覆盖补充验证；不靠修改生命、直接杀怪或跳楼层来宣称整局成功。
