# 遗物采集规则

遗物保持真实获得顺序。已经发生的获得效果跳过，保留历史产生的卡牌、升级、附魔；持续战斗效果由原版执行。普通计数在已适配的合法范围内可复现采样，见[计数范围](counter-state.md)。

## 单独移除，保留剩余构筑

影响最大生命的遗物从标准化输入移除，统一 70/70 开战。目录通过原版方法调用识别 `GainMaxHp`、`LoseMaxHp`、`SetMaxHp`、`ModifyMaxHp` 等影响；回血遗物不因回血而移除。另有下列 13 件明确按用户规则移除：

| 遗物 | ID | 处理要点 |
| --- | --- | --- |
| 异蛇之眼 | `SNECKO_EYE` | 移除其战斗效果 |
| 异蛇之眼？？？ | `FAKE_SNECKO_EYE` | 移除其战斗效果 |
| 巨大卷轴 | `MASSIVE_SCROLL` | 不撤销已经产生的牌 |
| 佩尔之眼 | `PAELS_EYE` | 不重建其未适配状态 |
| 黄金罗盘 | `GOLDEN_COMPASS` | 不执行依赖地图/幕的效果 |
| 药瓶皮套 | `PHIAL_HOLSTER` | 不增加药水槽或给予药水 |
| 石化蟾蜍 | `PETRIFIED_TOAD` | 不生成药水形状的石头 |
| 蜥蜴尾巴 | `LIZARD_TAIL` | 不执行复活 |
| 炼金箱 | `ALCHEMICAL_COFFER` | 不生成药水 |
| 娇嫩蕨草 | `DELICATE_FROND` | 不执行药水相关效果 |
| 涅奥的牺牲 | `NEOWS_SACRIFICE` | 保留实际先古选择历史 |
| 皮草大衣 | `FUR_COAT` | 不执行依赖地图位置的敌人生命修改 |
| 佩尔之牙 | `PAELS_TOOTH` | 使用该层可还原的实际牌组，不凭空返还暂存牌 |

来源审计分别记录 `removed_user_relics` 和 `removed_max_hp_relics`，原始 `.run` 不改写。先古来源按移除前真实持有关系核对；删除一个遗物不能绕过其余非法牌或状态检查。

## 获得效果与先古来源

目录使用显式白名单跳过已发生的删牌、变牌、加牌、升级、附魔、金币和奖励效果，不以“有获得回调”一概拒绝，也不对未知遗物一概放行。血染玫瑰的能量、大～抱抱的煤灰、腰带扣在无药水时的敏捷仍保留。

异鸟宝宝、佩尔的士兵使用合法默认外观，开战宠物仍由原版召唤。`ARCHAIC_TOOTH`、尘封魔典等已经完成的选择提示不重放，真实卡牌变化来自历史；这些展示状态不当作新的战斗计数。

第一幕对应涅奥，第二、三幕保留各自实际先古选择。达弗作为共享先古从 `ModelDb.AllSharedAncients` 单独导出，只能分配到第二/第三幕，同局最多一次。即使所选遗物被标准化移除，也保留先古历史，不把构筑挪到其他幕。

涅奥骨骰不再次发奖励；最多允许两个来源中实际获得且合法的额外涅奥候选，不能嵌套骨骰或据此加入二三幕先古遗物。神化、压制、涅奥之怒等已经产生的卡牌保留。

## 欧罗巴斯之触

静默在第二幕选择 `TOUCH_OF_OROBAS`，蛇之戒原位替换为龙之戒，欧罗巴斯之触自身保留。导入器核对先古选择、获得/移除记录、替换标识和最终顺序；第三幕继承这一状态，变异保护龙之戒与先古遗物。

原生从蛇之戒开局，不另行注入龙之戒；仅对欧罗巴斯之触执行一次原版获得效果，完成确定性替换。其他遗物仍跳过已发生的获得效果。最终实际开战遗物序列和计数必须与请求一致；不完整或矛盾历史拒绝。

## 仍然拒绝的输入

| 项目 | 原因 |
| --- | --- |
| 海玻璃 `SEA_GLASS` | 保存角色标识，涉及其他角色牌 |
| 玩具盒 `TOY_BOX` | 蜡制遗物身份、融化和战斗次数需要联合恢复 |
| 棱彩宝石 `PRISMATIC_GEM`、万花筒 `KALEIDOSCOPE` | 超出本轮静默永久牌组范围 |
| 未适配的保存状态、其他角色/多人限制、未列入移除清单的复活或药水效果 | 不猜状态，不自动删除后放行 |

导入修订统一见[版本规则](source-versions-and-scheduling.md)。规则变化可重审受影响的历史来源，旧报告和标签保留；文档不再列逐次回补数量作为当前队列总量。
