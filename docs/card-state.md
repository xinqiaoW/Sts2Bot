# 卡牌、升级与持久状态

当前导入修订：0.111 用 `special_cards_saved_state_v8`，0.109/0.110 用 `source_versions_109_110_v1`；原生采集协议 3。只收静默猎手。来源含 0.109、0.110、0.111，开战统一 0.111.0；A10、70/70、无药水，45 张上限和 0–5 张无色牌规则不变。精确版本/schema 白名单和恫吓转侧步见[来源版本](source-versions-and-scheduling.md)。

## 允许的牌与状态

真实永久牌组中的静默、无色、诅咒、事件/先古、任务、状态和衍生牌允许导入，仍须逐牌通过目录合法性与状态校验。富足（`ABUNDANCE`）及其升级版已接入。任务牌包含藏宝图、探寻、灯火钥匙和多尼斯异鸟蛋。变异新增牌仍来自普通静默/无色牌池，不随机添加任务牌。

| 牌 | 原生保存字段 | 还原规则 |
| --- | --- | --- |
| 藏宝图 `SPOILS_MAP` | `SpoilsActIndex` | 只接受原版第二幕值 1；默认值使用稀疏表示 |
| 探寻 `DOWSING` | `RoomsEntered` | 战前 0–4；进入问号房前推进，到 5 必须与历史变牌对应，战前已是富足 |
| 愧疚 `GUILTY` | `CombatsSeen` | 战前 0–4；胜利后推进，死亡不推进；历史完成状态不能直接作为未完成牌输入 |
| 疯狂科学 `MAD_SCIENCE` | `TinkerTimeType`、`TinkerTimeRider` | 还原攻击/技能/能力与九种合法效果组合；缺失或非法组合拒绝 |
| 多尼斯异鸟蛋、灯火钥匙 | 无额外保存字段 | 保留身份，变牌按真实历史处理 |

每张牌分别保存 ID、升级、附魔 ID/数值、持久状态。相同牌名但状态不同会产生不同构筑身份、去重键和模型特征；空状态保留旧无状态牌的序列化身份。升级、附魔并非根据牌名统一推断。

原生恢复顺序为创建卡牌、通过 `SavedProperty` setter 还原状态、再应用升级/附魔。输入使用 `persistent_state`，请求为 `savedIntegerMembers`，实际战前回读为 `persistentState`。协议 3 缺失回读、字段类型错误、逐张多重集不同均拒绝标签。

## 边界

飞溅等卡牌在战斗中产生的临时牌由原版执行；这些牌不倒灌为战前永久牌组。永久牌组中的其他角色牌、多人限定牌、废弃占位牌、炼制药水牌仍不接收。遗传算法、镰刀等其他角色牌的保存字段不因此开放。

未列入适配的字段或类型、无法核对最终牌组的历史、不能确定的混合房间时序会保留原因并跳过，不猜为默认状态。兼容旧版来源仅使用已明确转换且可按 0.111.0 还原的状态，不承诺任意旧版字段语义相同。

当前真实 v4、普通变异 v2、专项变异 v1 及新增补采结果记录协议 3 标签。旧协议 2 的 v3 / v1 已封存：`teacher_batch_origins` 记录接续出处，`prior_collected_inputs` 保存旧完成/隔离输入身份和结果摘要，防止重审后重复采集；不把旧结果重标成新协议。看板保留独立批次，见[查看数据](data-viewer.md)。原生校验范围与历史证据见[验证与审计](validation.md)。
