# 搜索预算与教师

| 参数 | 当前采集值 |
| --- | --- |
| 实际游戏 | 0.111.0 |
| 采集观察协议 | 3，支持逐张升级、附魔和持久状态 |
| performance preset | Medium |
| 搜索模式与软时间预算 | short_only，8,000 ms |
| 单场搜索并行度 | DOP 1 |
| 整场期限 | 120 秒 |
| 部署与 GC | Instant、动作间隔 0、NoGC 关闭 |
| 正常采集库 | 真实 v4、普通变异 v2、专项变异 v1 |

8 秒是每次搜索的软预算，不是固定回合深度，也不是每场总耗时。Medium 的短搜 Beam=24、节点上限 2,400、动作分支上限 20 仍会限制搜索；只提高时间不会自动扩大这些上限。原生检查日志还会列出深搜预算，但 short_only 不因此执行深搜。

每个 worker 在独立原版战斗中执行求解器路线，必须取得完整终局并校验后才记录标签。标签反映这套教师配置的实际表现，不是数学最优掉血；不能用某一轮更好的样例证明所有构筑都改善。

教师身份包含游戏、求解器、采集器和依赖摘要，以及模式、预算、并行度等设置，由 `configs/teacher.json` 和 session 核验。来源版本兼容和 24/4 战斗种子策略不改变实际游戏或教师；种子数量决定重复试验次数，不改变每场的搜索预算。新预算或新观察协议不得给旧标签改名；`teacher_batch_origins`、`prior_collected_inputs` 用于保留迁移出处并阻止重复采集。

旧真实 v2 为 2 秒历史批次，真实 v3 / 变异 v1 为已封存的协议 2、8 秒批次；不能继续领取。模型训练可按[训练兼容规则](../train/README.md)显式组合部分历史 8 秒标签，页面仍区分来源批次。

失败重试、隔离、内存和停止规则统一见[持续采集](continuous-collection.md)。
