# 高误差编组专项变异

策略 `configs/mutations-targeted-8s.json` 覆盖用户指定的 43 个编组：暗港 6、密林 7、巢穴 15、荣耀 15。名单是本轮固定采集目标，不根据当前预测值在线改变标签或筛除掉血高的结果。

## 分配与生成

真实、原变异、专项变异按成功领取任务数采用 50:25:25。25 个 worker 错开相位，循环领取真实、真实、原变异、专项变异；空队列借用其他队列。完成比例可能因战斗耗时、重试、空队列与重启产生偏差，不能把它解释为固定 CPU 配额。

专项先从有合法父代的编组中选择已生成构筑最少的目标，同数时可复现随机选择；按各编组均衡新增，不按误差表百分比加权。随后按卡牌组成均衡选父代，避免重复快照占据大部分概率。

父代必须是已有有效采集记录的真实构筑；目标必须在父代核实过的同一幕、来源前后两层范围内。只给子构筑安排所选的一个原版编组，不扩展全幕，也不跨幕。每对仍为 4 个既定种子。缺少合法父代的目标在 `target_coverage` 标为 unavailable；全部缺失则明确失败，不自行放宽规则。

小变异 60%、大变异 40%；小变异改 1–2 张牌或 1–2 件普通遗物，大变异改 3–6 张牌或 1–4 件普通遗物，允许同时变化。保留先古/初始等受保护遗物、幕与来源，沿用升级、附魔、持久状态、计数合法性以及卡组大小限制。只生成一代，不用变异后代继续繁殖。与真实库、原变异库及本库交叉去重。

## 保存与验收

专项数据库为 `data/collection-targeted-mutations-v1.sqlite`，双槽备份为 `backups/01-targeted-mutations-card-state`，状态为 `data/targeted-backup.json`。`mutation_focus` 保存选定编组，`mutation_lineage` 保存父子和改动，`mutation_target_origins` 保存来源窗口。保持父代 family/split，训练时须按血缘划分，不能把专项样本当成独立真实对局。

原生失败证据在 `evidence/native-failures-targeted-v1`；保留所有尝试，沿用现有重试/隔离和有效终局验收。教师仍为 8 秒短搜、DOP 1、A10、70 满血、无药水。旧数据不改写，模型不自动重训。

补充数量不等于模型误差一定下降；下一次训练应分别报告各编组、真实留出集和变异样本表现。当前训练/页面工具若只指定两库，需要显式加入第三库，不能误把两库合计当作全部采集量。
